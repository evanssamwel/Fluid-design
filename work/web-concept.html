Open Space

What changes when an editorial website gives its content more room to breathe?

Type
Responsive editorial website concept
Year
2026
Role
Independent layout and front-end exploration
Tools
Semantic HTML, responsive CSS, vanilla JavaScript
Deliverables
Page structure, type hierarchy, responsive layout concept
The question

Make reading feel unhurried.

Editorial layouts can become dense as more content is added. This concept explores generous spacing and a clear type hierarchy as tools for making long-form material feel approachable on both wide and narrow screens.

Goals & constraints

  • Support a clear reading order from title to supporting detail.
  • Keep line lengths and spacing comfortable on small screens.
  • Use decorative imagery without making it a prerequisite for understanding.
  • Build the concept with responsive, semantic HTML and CSS.

Design exploration

A compact, card-heavy route was compared with a more open editorial layout. The chosen direction reduces competing boxes, gives headings room to establish sections, and uses a single visual accent to maintain the project’s atmosphere.

Final direction & decisions

The concept favors a narrow text measure, responsive type sizing, simple navigation, and flexible spacing. The layout is intentionally content-first; imagery is supplementary, and its dimensions are declared to avoid layout shifts.

What I learned

Whitespace only helps when the content hierarchy is clear. A next iteration would add representative long-form content and review reading comfort at multiple viewport widths.
