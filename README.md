# Fluid Design

### Digital experiences, shaped to flow.

A responsive, multi-page portfolio concept with a fluid glass aesthetic, atmospheric color, and calm interactions. Built with plain HTML, CSS, and JavaScript — no frameworks, build tools, or runtime dependencies.

## Explore the site

| Page | What you’ll find |
| --- | --- |
| [`index.html`](index.html) | Landing page, design highlights, and featured concepts |
| [`about.html`](about.html) | The ideas and principles behind Fluid Design |
| [`work.html`](work.html) | Selected visual and interaction concepts |
| [`contact.html`](contact.html) | Contact details and project enquiries |

## Get started

Open `index.html` in a browser, or run a local static server from the project folder:

```bash
python3 -m http.server 8000
```

Then visit [http://localhost:8000](http://localhost:8000).

## Built with

- **HTML** for accessible page structure
- **CSS** for responsive layouts, glass surfaces, and fluid color
- **Vanilla JavaScript** for the shared navigation menu
- **Font Awesome Free 5** for interface icons

## Make it yours

1. Update the sample email address in `contact.html`.
2. Replace the placeholder social links (`href="#"`) across the pages with real profile URLs, or remove the icons you don’t use.
3. Replace the concept cards and gradient artwork with finished project details and images.
4. Adjust the theme tokens near the top of `css/flui-skin.css` to change the palette.

The homepage is `index.html`. `fluid-index.html` remains as a legacy redirect for older links.
